## 依賴方向

- `src/worker/*` → `src/shared/types.ts`；`src/frontend/*` → `src/shared/types.ts`（共享契約）
- `src/frontend/main.ts` → api.ts / backend-ssh-client.ts / bootstrap-runner.ts / folder-browser-state.ts / terminal.ts / sftp-panel.ts / monitor.ts
- `src/frontend/sftp-panel.ts` → sftp-paths.ts / sftp-file-kind.ts / sftp-preview.ts / preview-modal.ts / ui-icons.ts
- `src/frontend/preview-modal.ts` → highlight-language.ts（推斷語言）+ 動態 import `highlight.js/lib/core`（延遲 chunk，點擊預覽才載入）
- `src/frontend/monitor.ts` 內部動態 import `chart.js/auto`（延遲 chunk，連線後預載）
- `go-ssh/*` → `dist/worker/ssh.wasm` → `backend-ssh-do.ts`；瀏覽器產物不含 Go WASM/runtime
- `scripts/build-client.mjs`：esbuild 打包前端 + 複製 styles/fonts，並清除任何舊 `dist/client/wasm`
- `scripts/build-go.mjs`：只產生 Worker 後端 `ssh.wasm` 與 `wasm_exec.js`
- `.github/workflows/deploy-cloudflare.yml` → `scripts/cloudflare-deploy.mjs` → `cloudflare-deploy-lib.mjs` → Cloudflare D1/KV REST API；產物只寫入被忽略的 `.cloudflare-deploy/`

### GitHub 公開發布與 Cloudflare 手動部署（2026-08-25）

- GitHub repository：`https://github.com/s12ryt/worker-ssh`，公開、預設分支 `main`、MIT License。
- Workflow只接受 `workflow_dispatch`，以最小 `contents: read` 權限執行完整測試、typecheck、build、split、資源provisioning、Wrangler dry-run與deploy。
- Production固定命名：Worker `worker-ssh`、D1 `worker-ssh-db`、KV `worker-ssh-kv`。provisioning採完整名稱比對，存在則重用，不存在才建立，多筆同名安全中止。
- GitHub secrets：`CLOUDFLARE_API_TOKEN`、`CLOUDFLARE_ACCOUNT_ID`、`PANEL_PASSWORD`、`ENCRYPTION_KEY`；不由本機 `.dev.vars` 搬移。
- `.gitignore` 排除 secrets、local D1/KV state、dist、node_modules、screenshots、logs、network records、Playwright與deployment temp。Release contract會掃描公開來源，禁止內嵌private-key PEM。

## 外部服務/綁定

| 名稱 | 類型 | 用途 |
|------|------|------|
| KV | Cloudflare KV namespace | OS 快取、登入限流與舊 conn:* bootstrap 遷移來源 |
| DB | Cloudflare D1 | folders/connections 唯一主儲存、schema/bootstrap 狀態 |
| SSH_SESSIONS | Durable Object namespace | 非休眠後端 SSH WebSocket session 與 Go WASM runtime |
| SSH_QUOTA | Durable Object namespace | 持久化 active SSH lease；同登入 session 3 條／全域 10 條配額 |
| PANEL_PASSWORD | Worker secret | 面板登入密碼 |
| ENCRYPTION_KEY | Worker secret | D1/KV 加密信封與 folder name HMAC token 金鑰來源 |
